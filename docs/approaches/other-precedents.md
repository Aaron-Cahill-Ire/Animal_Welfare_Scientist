# Other precedents

| System | Pipeline | Relevance |
| --- | --- | --- |
| Google AI Co-scientist | Generation → reflection → ranking tournaments → evolution → meta-review → expert/experimental validation | Explicitly separates generating hypotheses from criticising and ranking them. [Google Research](https://research.google/blog/accelerating-scientific-breakthroughs-with-an-ai-co-scientist/) |
| Sakana AI Scientist | Brainstorm ideas → check novelty → plan and run experiments → analyse results → automated peer review → feed criticism into later iterations | Demonstrates an end-to-end engineered research loop, although it is mainly suited to computationally testable ideas. [Sakana AI](https://sakana.ai/ai-scientist/) |
| FutureHouse | Literature search and data analysis → hypothesis generation → experiment design → testing → update the system’s model | Shows how discovery can be grounded in evidence and empirical results. FutureHouse explicitly says that no system has yet fully met its ideal definition of an autonomous AI scientist. [FutureHouse](https://www.futurehouse.org/ai-scientist) |
| ResearchAgent | Retrieve related literature and cross-domain concepts → propose problems/methods/experiments → obtain feedback from reviewing agents → revise | Particularly relevant to discovering ideas through connections across fields. [ResearchAgent paper](https://arxiv.org/abs/2404.07738) |
