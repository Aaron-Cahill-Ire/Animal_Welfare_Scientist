# Scientific Discovery

> **Status:** Exploratory approach family; not implemented or validated

Use this family when the main uncertainty is scientific: the causal mechanism
is unclear, competing explanations remain plausible, or it is unknown whether
changing a proposed process will improve welfare.

## Current approach

- [Mechanism and hypothesis loop](mechanism-hypothesis-loop.md) — generate
  source-grounded causal hypotheses, turn them into measurable tests, analyse
  real results and update the hypothesis.

## Intended output

The primary output is new empirical knowledge:

- which mechanism appears important;
- which proposed relationship was weakened or supported;
- which measurement or experiment was informative; and
- what should be tested next.

Finding a deployable intervention may follow, but it is not the immediate
success criterion. Once the work establishes a sufficiently clear required
change, it can move into
[intervention discovery](../intervention-discovery/README.md).
