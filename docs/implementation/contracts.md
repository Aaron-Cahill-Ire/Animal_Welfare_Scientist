# Implementation contracts

The accepted specification is docs/plans/2026-09-13-animal-welfare-science-agent-commons-prd.md, especially §11.1–11.3. Original user documents are preserved untouched. Native Python 3.9+ monorepo; no required paid provider. Deterministic bounded research assistance must disclose its limits; no pretend model calls or fixture replay. Actual video decoding may use an optional declared backend. No external tools or generated code are executed by the runner.

Each track module `commons/agents/track_a.py`, `track_b.py`, `track_c.py` exports:
- `SPECS`: dict keyed by A1…C6. Each value includes `name`, `task`, `required` (list of required payload keys), `input_schema` and `output_schema` (JSON-schema subset: type, required, properties, items, enum), `limitations` (list), `modalities` (list), `example` (supported synthetic/public payload), `baseline` (description).
- `run(agent_id, payload)`: computes and returns dict with `status` (completed, partial, abstained, awaiting_human, awaiting_external, unsupported_input), `data` dict, `warnings` list, optionally `required_action` string. No envelope metadata, files or external side effects. Handle missing domain evidence by partial/abstention, never make it up.
- `baseline(agent_id, payload)`: real simple comparison returning same domain result shape.
- `benchmark_cases()`: list of dicts {id, agent_id, category, input, check}. `check` is a callable(result) -> bool; result is domain result from run (status/data/warnings). Each agent covers ordinary, missing/ambiguous, misleading/adversarial, and task-specific failure with semantic assertions. Stored scores will be generated by main harness, not invented.

Shared runner validates input and output schemas and wraps output with schema_version, run_id, agent_id, agent_version, configuration_snapshot, input_sha256, sources, runtime_seconds, cost_usd, backend, status, data, warnings, required_action, human_review_required. Missing mandatory input returns abstained/actionable required_action before dispatch. Source records live in payload.sources [{id, passage, url?, context?}] and propagate unchanged, but private input is rejected. Handler schemas validate payload/data; handlers need not reimplement generic validation. All payloads default to synthetic/public only; `data_classification` must be public or synthetic.

Modules exclusively own their own file and tests/test_track_X.py. No shared files, Git operations, installs or broad formatter/build runs by workers. Tests may run with PYTHONDONTWRITEBYTECODE=1. Main agent owns runner, CLI, workflow orchestration, docs, catalogue, website generation and authoritative evaluation.

Testing: unittest full integration, schema failures, exact numeric checks, abstention, cross-context and measurement/intervention distinction, source ID handoffs, gate pause/resume and budget limits. Actual results remain preliminary, developer-graded; no independence, efficacy or field-validation claim. Any unsupported part of PRD remains explicitly pending in release checklist.
