# Archive

This folder preserves work that is not part of the current pipeline comparison.
It remains available for reference and may later supply useful components.

## Contents

- [`agent-commons`](agent-commons/README.md) — the deterministic Agent Commons
  implementation, including 20 small research utilities, tests, benchmarks,
  sample workflows, catalogue data, website assets and implementation plans.
- [`historical-designs`](historical-designs/) — the original combined Animal
  Welfare Research Loop baseline and earlier broad product proposals that
  predate the current two-family approach structure.

Archiving does not mean that this work was disproved or abandoned. It means it
is not currently one of the documents being used to choose the LLM pipeline.
