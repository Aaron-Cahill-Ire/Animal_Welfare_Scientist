EVIDENCE, NOT ENDORSEMENT

Read the result behind the label.

Prototype

An implemented bounded task, real example output, and preliminary developer-authored checks. Costs and failures are recorded.

Evaluated

A frozen scientific evaluation with a matched baseline and explicit decision rule. No Commons version currently claims this status.

Independently verified

External welfare and methods reviewers must approve version-specific evidence. No independent verification has occurred.

Maintenance and security labels are separate. “Unreviewed” is not an endorsement to execute an external repository.
